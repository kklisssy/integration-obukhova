# Синхронизация CMS с PostgreSQL в n8n

Workflow получает данные из CMS API с учётом пагинации, добавляет и обновляет их в PostgreSQL, сохраняя детали, удалённые из CMS. Затем формирует отчёт в формате CSV и отправляет его в Report API с Bearer-авторизацией.

Работа выполнена с использованием n8n и PostgreSQL. Для формирования CSV используется JavaScript.

Workflow экспортирован в файл `Obukhova integration n8n.json`. Файл `schema.sql` содержит SQL для создания таблицы, необходимой для работы интеграции.

## Подготовка

1. Создайте базу в PostgreSQL.
2. Откройте Query Tool в pgAdmin именно для этой базы и выполните содержимое `schema.sql`.
3. Запустите n8n.
4. Импортируйте `Obukhova integration n8n.json` через меню workflow → Import from File.

## Подключения

Создайте Postgres credential и выберите его во всех трёх узлах PostgreSQL.
В узле «Получение токена» замените `MY_PASSWORD` своим учебным паролем (для `student30`).

## Запуск и проверка

1. Проверка подключения PostgreSQL.
2. GET `/cms/spares`: страницы с нуля, размер страницы 10, завершение при пустом массиве.
3. Добавление и обновление деталей в БД параметризованным SQL.
4. Чтение всей таблицы один раз за запуск.
5. Формирование CSV без заголовка: UTF-8, разделитель `;`, перенос строки LF.
6. POST `/auth/token`: получение нового токена.
7. POST `/report/csv`: отправка CSV с заголовком Authorization: Bearer.
